# Shubh IT Solution 🖥️

A professional IT services & computer repair business website built with Bootstrap 4, Revolution Slider, and modern web technologies.

## 🌟 Features

- **Responsive Design**: Mobile-first, works on all devices
- **Revolution Slider**: Professional animated hero sections
- **Multiple Pages**: Complete business website template
- **Dark Mode**: Alternative dark theme available
- **Contact Form**: PHP-powered contact functionality
- **Animated Elements**: WOW.js scroll animations
- **Font Awesome Icons**: Rich icon library

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RajmaniShukla/shubhitsolution.git
   cd shubhitsolution
   ```

2. **Open in browser:**
   - Simply open `index.html` in your web browser
   - Or use a local server like Live Server (VS Code)

3. **For contact form:**
   - Upload to a PHP-enabled server
   - Configure `contact.php` with your email

## 🎨 Customization

### Changing Colors
Edit `css/colors1.css` to modify the color scheme:
```css
:root {
  --primary-color: #your-color;
  --secondary-color: #your-color;
}
```

### Logo Replacement
Replace images in `images/logos/` folder.

### Contact Information
Update phone and email in the header section of HTML files.
